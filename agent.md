# Agent Instructions

Your primary focus is the two repositories:
- caly-ai-frontend
- caly-ai-backend

Do not treat the root Caly Ai directory as a repository; avoid making changes directly in this root folder unless explicitly instructed to modify shared configuration or documentation that applies to both repos.

When starting work, cd into the appropriate repo before executing commands.

After making any changes, always run `git add .` and `git commit` to save your work and prevent losing code.
