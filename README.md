# Caly AI Backend

Express + MongoDB (Mongoose) + OpenAI calorie-tracking API.

## Quick start
```bash
cp .env.example .env
npm install
npm run dev
```
API: http://localhost:5000/health

## Structure
`src/config` `src/middleware` `src/models` `src/routes` `src/controllers` `src/services` `src/utils`
